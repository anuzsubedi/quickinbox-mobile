# QuickInbox Mobile

QuickInbox Mobile contains the native Android and iOS clients for QuickInbox.

## Projects

- `android/` — Jetpack Compose Android app
- `ios/` — SwiftUI iOS app

The clients pair with a self-hosted QuickInbox server. Platform-specific build
requirements and commands are documented in each project directory.

## Repository policy

This repository contains application source, assets, and build configuration.
It intentionally excludes signing credentials, platform account identifiers,
generated build output, screenshots, and local development state.
